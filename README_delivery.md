# 应急智航 动态优先级调整系统

当前主线是应急物资运输任务的动态优先级调整。界面可运行时间仿真、注入事件、观察实时队列与评分曲线，并对比 G0/G1/G2。

## 启动

Windows 双击 `run.bat`，选择 2 启动。当前机器已创建项目 `.venv`。

其他环境使用 Python 3.10+：

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m streamlit run app.py --server.headless true
```

浏览器访问 http://localhost:8501 。验证：

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -v
```

## 推荐演示

1. 使用默认“中途新增急救”、G2、2 架无人机、seed=42。
2. 点击“推进 60 秒”两次，查看 120 秒发布的 EM01 进入队列及对应日志。
3. 查看等待任务的排名、分数曲线、分项记录；正在配送的批次不会被抢占。
4. 暂停后可新增急救、追加需求、提升等级或取消任务。
5. 点击“运行三策略对照”，查看同一预设和种子下 G0/G1/G2 的完整运行结果。
6. 下载运行 JSON、评分 CSV 和对照 CSV。人工注入事件包含在运行 JSON 中，不包含在预设对照实验中。

## 规则

- P=35E+30B；B=clip(0.30U+0.25T+0.20S+0.15N+0.10A)。迟到不再扣分，单独统计准时率。
- 时间压力 T=clip(1-(deadline-now-service)/300)，服务耗时为场景给定估计值。
- S=(需求-已交付)/需求；N=clip(log(1+人数)/log(1001))；A=clip(等待秒数/300)。
- 等级 E0/E1/E2 分别对应 0～30、35～65、70～100。等待不能跨等级。
- 仿真每秒推进；每 5 秒以及发布、事件、交付、返仓和失效时重排。
- G0 按发布时间与编号；G1 按当前严重度与发布时间、编号；G2 按 P、软截止、发布时间、编号。
- 每批最多 5 kg；同一父任务同时只有一个未交付批次。单程耗时固定，返仓耗时等于单程。可部分交付。
- 执行批次不抢占；取消或硬失效后禁止新发运，在途货物不再交付，按原返回时刻返仓。
- 同刻顺序为预设事件、发布/失效、交付与返仓、重排与派机。恰好失效的交付不计成功。
- 到结束时间停止派机并保留未完成状态。配置修改后暂停旧运行，只有“加载并重置”才应用新配置。

| app.py | Streamlit 交互、曲线、日志、下载和对照 |

## 边界与指标

本系统是内存中的教学仿真，无真实飞控、航路冲突、电量、数据库、登录权限和自动恢复。页面会话结束可能丢失状态，应及时下载。权重是人工设定，动态策略不保证每个场景都优于基线。

完成率和准时完成率的分母是截至当前已发布任务数（包括已取消和已失效任务）。准时要求父任务全部交付不晚于软截止。急救首次派送等待只对当前等级 E2 且已派送任务取均值，同时显示未派送数；人工升级任务也按原发布时间计算。普通最长等待包含未完成任务。未满足需求包含失效缺口，排除取消任务。
