# 应急智航 · 双向交叉口优先通行

基于 Python 和 Streamlit 的无人机通行教学仿真。当前主程序展示北、东、南、西四个进口，以及左转、直行、右转和持续生成的无人机流量；支持动态紧急度、信号协调、极端应急借道、状态调整和运行数据导出。

## 安装与启动

需要 Python 3.10+。Windows 可双击 `run.bat`，在菜单中先选择 **1 安装依赖**，再选择 **2 启动主应用**；选择 **5 一键体检**会依次安装依赖、运行测试、启动应用，任一步失败即停止。

也可在项目目录中手动执行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py --server.headless true
```

macOS / Linux：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py --server.headless true
```

浏览器访问 http://localhost:8501 。按 `Ctrl+C` 停止服务。虚拟环境应在本机创建，不要从其他电脑复制。首次安装依赖需要网络连接。

## 演示操作

1. 选择通行策略、每批生成数量和随机种子。策略或种子修改后，点击“重置场景”应用；默认种子为 `20260927`。
2. 点击“单步 1 秒”或“推进 10 秒”观察放行决策，也可开始播放并选择 1、2、5 倍速。持续流量模式不会自动结束。
3. 点击场景中的无人机可自动暂停并选中，也可通过侧栏选择。调整任务等级、剩余限时、累计等待或暂停状态，再点击“应用状态并重新评分”。已放行的无人机只能查看。
4. 演示极端紧急：暂停后选取尚未放行的无人机，将任务等级设为 T5、剩余限时设为 8 分钟；系统自动判定为 E2。单步观察全红、清空和放行日志。
5. 查看分紧急状态的平均通过耗时、评分排行、全部状态和决策日志。暂停后下载 JSON 保存当前快照；表格也支持 CSV 下载。

相同种子、策略、生成数量和操作序列可以重复演示。不同策略可能改变入口拥堵和后续生成，因此相同种子不代表两种策略一定获得完全相同的任务输入，不应直接据此认定策略优劣。

## 当前模型

- 四进口双向两车道，每个方向一条连续车道；初始 12 架无人机。
- 每 5 个仿真秒尝试生成 1～4 架；入口空间不足时，本批实际生成数量减少。
- T1～T5 的生成权重分别为 40%、25%、18%、11%、6%；限时由均值 20 分钟、标准差 10 分钟的正态分布产生，最低为 3 分钟。
- 紧急状态由任务等级和剩余限时自动计算。Tn 的 E1 阈值为 `10 + 2×(n−1)` 分钟，E2 阈值为 `5 + (n−1)` 分钟，严格小于阈值时升级。
- 常态按进口轮转；E1 延长本进口放行；E2 触发全红，等待冲突占用清空，必要时借道。具体解释见页面“放行规则”。
- “先到先行”仍保留紧急等级优先及信号约束，同等级候选按到达等待线时间排序，并非完全忽略紧急任务的基线。
- 时间使用 0.1 秒固定步长；页面播放约每 0.2 秒更新。分紧急状态平均耗时统计从到达等待线至清空路口的时间，包含等待，按清空时的 E 等级归类。

这是同高度、简化几何的教学模型，不用于真实飞控。会话数据保存在内存中，重置前请导出。持续运行会裁剪较早的已完成无人机记录，累计完成数与汇总指标仍保留；导出不是完整轨迹或可直接恢复的存档。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `app.py` | 交叉口页面、动画、控制与导出 |
| `crossing.py` | 仿真推进、紧急度、信号与放行规则 |
| `launcher.py`、`run.bat`、`run.sh` | 启动菜单与平台入口 |
| `tests/` | 仿真、界面和启动流程测试 |
| `delivery_app.py`、`simulation.py`、`priority.py` | 保留的旧配送实验，参见 `README_delivery.md` |
| `应急智航_预设场景包/` | 旧版场景配置和生成工具，未接入当前交叉口页面 |
| `应急智航_完整修订方案.md` | 设计参考，包含尚未实现的规划功能 |

JSON 导出包含模型版本、种子、当前参数、无人机状态、事件日志及统计信息。预设场景的 `resolved/` 数据可按场景包说明重新生成，不纳入 Git。

## 验证与常见问题

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

- 提示缺少 Streamlit：用启动应用的同一 Python 执行 `-m pip install -r requirements.txt`。
- 8501 端口被占用：启动命令增加 `--server.port 8502`，访问对应端口。
- 策略或种子修改后无法开始：点击“重置场景”应用设置。
- 未出现网页：保持启动终端运行，并手动打开上方浏览器地址。
