# 应急智航 交汇区优先通行样板

本版聚焦两条固定单向航路、一个二维交汇区、10 架无人机的完整通行过程。默认入口为 app.py，原配送排序程序保存在 delivery_app.py，旧说明保存在 README_delivery.md。

## 启动

双击 run.bat，选择 2；浏览器访问 http://localhost:8501 。也可执行：

```powershell
.venv/Scripts/python.exe -m streamlit run app.py --server.headless true
```

新机器使用 Python 3.10+ 创建虚拟环境并安装 requirements.txt；不要拷贝其他机器的 .venv。本机已有虚拟环境的解释器路径已修复。

## 三分钟演示流程

左侧“调整无人机状态”可选择尚未获准的无人机，修改任务等级、剩余时间、累计等待基值，或暂停/恢复该机，点击“应用状态并重新评分”立即生效。需要先暂停播放。等待基值为人为演示输入，修改记录会明确标注，之后继续累计实际受阻时间。已获准对象不允许修改，暂停前机会阻挡同航路后机。

“实时评分排行榜”显示等级分、时间分、等待分及总分，并用堆叠条形图展示构成。全体评分排名与队首候选顺序分开显示，高分后机不会越过前机。应用修改后，提示会显示分数和候选顺序的前后变化。

验证三项评分的效果：重置后将 D01 改为 E2，单步后 D01 获准；若要比较时间与等待因素，可将 D01、D02 都改为 E1，剩余时间分别设为 50s、10s，等待都为 0，此时 D02 优先；再把 D01 等待基值改为 60s，D01 的等待补偿使其成为第一候选。选择“动态优先”时这些评分才用于放行，“先到先行”仍按到达顺序。

1. 默认动态优先，先点击“单步 1 秒”。D02 获准，图中出现绿色圆环；D01 在等待线停住。右侧解释任务等级、剩余时间、等待时间与候选分数。
2. 再推进 7 个单步，到第 8 秒，D02 到达 +80m 并释放预约。此时交汇区暂时没有获准对象，仍需等待 2 秒安全间隔。
3. 点击“开始”，观察同航路排队和交替放行；可调至 5 倍速，整轮默认运行共 116 个仿真秒。
4. 演示等级变化：重置，暂停状态下把 D01 提升到 E2，再单步。D01 首先获准；已获准对象不会被其他事件抢占。
5. 切换“先到先行”并重置，单步后 D01 首先获准。两种策略使用完全相同的初始位置和任务数据，便于解释排序差异。人工等级调整需分别重复，才构成相同输入的比较。
6. 运行结束观察完成数、准时数与平均等待；下载 JSON 留存本次轨迹终态、参数和决策日志。状态表自带 CSV 下载。

## 简化模型与通行规则

- A 航路西向东，B 航路南向北，中心坐标 0；速度 20m/s，终点 +440m。
- 交汇区为中心 ±50m；等待线 −80m，单架预约持续至 +80m，随后清空等待 2s。
- 同航路相邻无人机至少间隔 70m，不允许超车。只有抵达等待线的队首参与放行排序。等级高的后机不能穿过前机。
- 先检查预约占用和清空间隔，再选候选对象。固定几何保护区保证候选进入时与另一航路等待对象隔开；沿航路运动另受前机安全距离限制。
- 动态分 P = 40E + 20T + 15W。E 为 0/1/2；T=clip(1−剩余秒数/60)；W=clip(累计受阻秒数/60)。clip 限制在 0～1。剩余秒数为任务截止时间减当前时刻。
- 同分按截止时间、编号。等级占主导且不跨级，等待补偿只改变同等级竞争；这不保证持续新增高等级任务时低等级任务不会饥饿。
- 先到先行按到达等待线的时间，再按编号；动态分在该模式中仅供参考。
- 等待时间只累计尚未获准、被前机或等待线阻挡而停止的时段。截止时间在到达终点时判定，逾期仍继续通行。
- 时间按 0.1s 固定步长推进，画面约每 0.2s 刷新；首次点击开始即推进一个刷新周期。获准后不抢占。
- 小于 0.1s 的推进时间会累积到下一步，不会被舍入丢弃；负数和非有限时间会被拒绝。
- “跟随飞行”表示仍在移动，“跟随排队”表示停住等待前机；已完成任务的剩余时间和动态分均冻结在抵达时刻。

本版是同高度、点质体教学仿真，参数为人工演示设定，不涉及真实飞控、航路规划、换层、配送需求等；不能据此认定实际飞行安全或动态策略普遍更优。无人机从接近交汇区的固定队列开始，任务与无人机一一对应。会话状态在内存中，重置或结束会话可能丢失记录。

## 文件与验证

- app.py：动画、播放控制、评分说明、等级提升、数据导出。
- crossing.py：固定步长仿真、安全预约、跟随距离与排序。
- tests/test_crossing.py：两种策略完整运行、每步间隔和互斥、清空间隔、非抢占、评分与页面操作。
- delivery_app.py、simulation.py、priority.py：保留原配送实验。

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -v
```
